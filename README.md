# BLK CAB® — Coffee & People

A modern responsive website for **BLK CAB® Coffee & People**, built to present the brand, menu, locations, ordering flow, and visual identity through a clean frontend experience.

This project is shared publicly as a portfolio showcase for frontend development, UI implementation, responsive layout, and brand-focused web presentation.

## Overview

BLK CAB® is a coffee brand website focused on visual storytelling, simple navigation, and a strong identity around coffee culture and people.

The application includes a homepage, menu page, about page, locations page, and a dedicated brand-story page for “Mind The Cab”.

## Features

- Responsive landing page
- Video-led hero section
- Brand story section
- Menu page
- About page
- Locations page
- “Mind The Cab” Game
- Order-ahead call to action
- Mobile-friendly navigation
- Reusable component-based structure
- Tailwind CSS styling
- shadcn/ui component system

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Radix UI
- React Router
- TanStack Query
- Lucide React

## Project Structure

```txt
src/
├── assets/          # Images, logos, and brand visuals
├── components/      # Reusable sections and components
├── components/ui/   # shadcn/ui components
├── hooks/           # Custom React hooks
├── lib/             # Utility functions
├── pages/           # Route-level pages
├── App.tsx          # Main routes and providers
└── main.tsx         # React entry point
```
